# Politics Economy 2.1.1

Minecraft 1.21.1 / NeoForge 21.1.252.

Politics Economy 2.1.1 — текущий этап:
- государственный склад использует конкретные Minecraft item id, а не FOOD/METAL/WOOD/FUEL;
- материальное содержание строительных блоков определяется их реальными crafting-рецептами;
- национальное потребление считается по конкретным ингредиентам блоков, стоящих на территории страны;
- альтернативные ингредиенты рецепта хранятся как "один из" допустимых предметов;
- дефицит конкретного материала накапливается как материальный долг;
- Modern UI показывает конкретные материалы, склад, расход и долг;
- старый абстрактный national upkeep больше не запускается.

Основные команды:
- /pe economy — открыть UI
- /pe economy deposit <item_id> — сдать конкретный востребованный предмет из инвентаря
- /pe economy deposit all — сдать все предметы из инвентаря, которые сейчас входят в потребление страны
- /pe economy development — показать развитие
- /pe economy development upgrade — повысить уровень (лидер/OP), если хватает очков и нет ресурсного долга
- /pe economy materials — показать потребление по конкретным материалам и рецептам
- /pe economy stockpile — посмотреть государственный склад по item id
- /pe economy stockpile add <item_id> <amount> — тестово добавить конкретный материал (OP)
- /pe economy stockpile set <item_id> <amount> — установить запас конкретного материала (OP)
- /pe economy run — тестовый экономический цикл для OP

## Этап 2 — дефицит и физические последствия (реализовано)
- обычные ресурсоёмкие инфраструктурные блоки при сохраняющемся материальном долге постепенно разрушаются;
- за один экономический цикл по каждому проблемному материалу уничтожается максимум один подходящий обычный строительный блок;
- уничтожение не списывает и не отменяет долг;
- Create и поддерживаемые Create-addon машины не уничтожаются;
- при любом материальном долге страны их работа приостанавливается;
- после полного погашения всех материальных долгов машины автоматически возобновляют работу;
- Createdieselgenerators: обычный, modular и huge diesel engine также останавливаются при долге;
- для Create дополнительно блокируется фактическая обработка Press/Basin/Crafter/Spout/Deployer, чтобы машина не продолжала производить результат во время долга;
- альтернативные ингредиенты сопоставляются по пересечению конкретных item id;
- ключевые блоки PoliticsMod защищены от разрушения; Residential Building больше не влияет на население.

### Важно
Модуль пока не собирался Gradle в этой среде: в архиве нет Gradle Wrapper, а системный Gradle не установлен. Исходники проверены на структурные ошибки, но финальную `compileJava`/runtime-проверку нужно выполнить в твоём локальном проекте через `gradlew.bat clean build`.


## Этап 3 — адресный контроль предприятий
- Create/Create-addon предприятия запоминают конкретные material dependencies своей обработки;
- если долг касается конкретного материала, независимые предприятия могут продолжать работу;
- неизвестные предприятия сохраняют безопасный fallback: останавливаются при любом материальном долге страны;
- зависимости предприятия сохраняются в SavedData и переживают перезапуск сервера;
- при поломке/разрушении машины её запись зависимости удаляется.


### Адресная проверка предприятий
`RecipeApplierMixin` запоминает конкретные item-зависимости рецепта в позиции Create-предприятия. Для Sequenced Assembly эти зависимости также фиксируются. Если страна должна, например, `minecraft:iron_ingot`, остановятся предприятия, использующие железо, тогда как предприятие, зависящее только от `minecraft:wheat`, может продолжать работу. Пока предприятие ещё не успело определить рецепт, используется безопасный fallback старой системы — остановка при любом материальном долге страны.

## Hotfix — Economy UI custom payload
- Fixed `EncoderException` when opening `/pe economy`.
- Material choice keys are shortened for network display when they exceed the packet string limit.
- All material arrays use the same maximum size (32) during encode/decode.
- Material strings are safely limited before `writeUtf`.
- The fix addresses long recipe alternatives such as plank/tag-based ingredients and prevents array-size desynchronization.


## Этап 4 — государственная политика (реализовано)
- форма правления: демократия, коммунизм, монархия, фашизм;
- религия: светское государство, христианство, ислам, буддизм, иудаизм;
- лидер выбирает каждую политику один раз; OP может менять их для тестирования;
- эффекты складываются с существующим экономическим направлением;
- население считается по кроватям в чанках страны/города; Residential Building больше не является источником населения;
- население даёт до +25% рабочей эффективности, а правительство и религия дополнительно изменяют её;
- эффекты применяются к добыче, Create, военному Create Big Cannons, торговой комиссии и содержанию инфраструктуры;
- /pe info, /pe profile, /pe government и /pe religion показывают текущую политику.

## Будущее — исследования
Исследования пока отложены до момента, когда список модов сборки будет окончательно определён. Планируемая архитектура будет открывать рецепты конкретных модов через data-driven требования, не жёстко зашивая неполный список модов в Politics Economy.

## Этап 5 — Survival starter kit и инфраструктурный прогресс
- Первый вход игрока выдаёт одноразовый стартовый набор: все 5 каменных инструментов, 16 хлеба, полный комплект кожаной брони, Tax Block, City Stone и Founding Stone.
- Получение набора помечается в PersistentData игрока, поэтому повторный вход/перезапуск сервера не дублирует предметы.
- Founding Stone, City Stone и Residential Building в PoliticsMod 0.3 имели creative-only UI; точечные mixin-фиксы Politics Economy разрешают их использование в Survival, сохраняя штатную логику PoliticsMod.
- Для PoliticsMod добавлены Survival-рецепты:
  - City Stone;
  - Residential Building;
  - Embassy;
  - Radar;
  - Vault.
- Trade Warehouse уже имеет штатный Survival-рецепт в PoliticsMod 0.3.
- Founding Stone намеренно не имеет рецепта и не продаётся через магазин.
- Tax Block получается через `/pe shop buy tax_block [1-16]` за казну государства.
- Цена Tax Block растёт от общего количества Tax Block в стране. При стандартном доходе PoliticsMod ($50 за блок за цикл): следующий блок начинается с $250, при 10 уже установленных — $1500, при 50 — $16500, при 100 — $57750.


## Этап 6 — население по кроватям (реализовано)
- 1 кровать = 2 жителя.
- Население страны — сумма кроватей во всех чанках, принадлежащих стране.
- Население города — сумма кроватей только в чанках, назначенных этому городу.
- Счётчики кроватей по чанкам хранятся в SavedData и переживают перезапуск игры/сервера.
- При загрузке чанка количество кроватей пересчитывается заново.
- При размещении или разрушении кровати затронутые чанки пересчитываются автоматически.
- Рабочая сила, политические расчёты и экономический UI используют новый показатель.
- Residential Building больше не нужен для роста населения; его можно использовать как обычный строительный/визуальный блок.


## Этап 7 — правила заселения и одноразовый стартовый набор
- В население попадает только кровать с крышей: над головой кровати должен быть непрозрачный/solid-render блок не дальше пяти блоков.
- Если две кровати находятся на одной вертикальной линии (одинаковые X/Z, отличается только Y), ни одна из них не считается населением.
- Это не позволяет получать жителей из декоративных вертикальных стопок кроватей.
- Стартовый набор теперь фиксируется в отдельном SavedData мира по UUID игрока.
- Старый player-NBT маркер поддерживается для миграции со старой версии.
- После выдачи набор больше не выдаётся при повторном входе в мир/на сервер.
